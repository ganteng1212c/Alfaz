# Alfaz Team Website

A modern, responsive website for Alfaz Team featuring galleries, booking system, and media management.

## Features

- 📱 Fully responsive design for all screen sizes
- 🖼️ Dynamic media galleries with image and video support
- 📂 Folder-based organization system
- 📅 Booking management system
- 🔐 Secure admin panel
- ⚡ Fast and optimized performance

## Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL (for database management)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/[your-username]/alfaz-team.git
```

2. Set up your web server (e.g., XAMPP, WAMP) and configure PHP

3. Import the database (if applicable)

4. Configure your environment settings

## Usage

### Client Side
- Browse galleries
- View media (images and videos)
- Make bookings
- Contact support

### Admin Panel
- Manage media content
- Create and organize folders
- Handle bookings
- Upload new content

## Security

- Protected admin routes
- Secure file upload system
- Input validation and sanitization
